Support

Cicada.OS is open source and has no company behind it. If it is useful to you, this is where you can help pay for the hardware it has to be proven on.

What this actually funds

HONEST

The single biggest limit on this project is written on the front page: most of the hardening is verified structurally, and much of it has never been exercised on real hardware end to end. That is not a coding problem. It is a hardware problem — a chipset watchdog either resets a board or it does not, a kernel either refuses a USB device at authorized_default=0 or it does not, and no amount of testing on a MacBook Air answers it for a Framework or a ThinkPad.

  • Test hardwareTPM2 + Secure Boot laptops to move claims off the “needs the machine” list
  • RadiosLoRa hardware for cicada-beacon — currently unproven
  • HostingThe signed cicada-stable package mirror

There is no perk, no token, no roadmap vote and nothing is owed to you in return. Cicada is pre-alpha — if you would rather wait until it is worth trusting, that is the more sensible choice, and the software stays free either way.

Check the address before you send

IRREVERSIBLE

A donation page is worth compromising, and a single altered character sends your money to someone else with no way back. Do not trust this page because it looks right — every address above carries its own checksum, and your wallet verifies it for free:

  • BTCbech32 checksum — a wallet rejects a mistyped bc1… outright rather than sending
  • ETHEIP-55 — the mixed upper/lowercase is the checksum. Do not lowercase it
  • SOLbase58, decoding to exactly 32 bytes — a wallet rejects anything else

These same three addresses are in DONATE.md in the source tree, where they are covered by git history. If this page and that file ever disagree, trust neither and open an issue — that disagreement is what a compromise looks like. Send a small amount first.

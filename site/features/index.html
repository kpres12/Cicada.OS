Features

GrapheneOS is the north star for intent. This page lists what Cicada actually ships on a laptop — policy OS on Linux, not Android kernel sandboxing.

Exploit mitigations

  • Kernellinux-hardened boot entry + lockdown on that entry
  • Memoryinit_on_alloc / init_on_free on cmdline
  • CETibt + shstk where silicon supports it — not MTE

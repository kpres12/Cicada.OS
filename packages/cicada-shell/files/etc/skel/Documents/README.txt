Cicada home folders
===================

Desktop/     — icons you can click (Files, Wi-Fi, Web, Doom, Power, …)
Documents/   — papers, notes, exports
  fizzbuzz.c — Tirimid item 3 starter (see below)
Downloads/   — browser and app downloads land here
Pictures/    — screenshots and wallpapers
Music/ Videos/
Templates/   — right-click → Create New → Text File / Script

Open any of these with the Files icon (dock or Desktop), or Super+E.
Files is a full manager: Places sidebar, New Folder, Trash, rename, USB.
Look: void black + amber (same HUD as Waybar / Kitty) — not Ubuntu purple.

After install, this tree survives reboot.

FizzBuzz (terminal):
  cd ~/Documents
  nano fizzbuzz.c
  gcc -o fizzbuzz fizzbuzz.c
  ./fizzbuzz
